よくある質問

ウィンドウが動きません／「許可が必要です」と出ます

Layout PinSpot は、ウィンドウの位置と大きさを読み取って動かすために、macOS の許可を2つ使います。システム設定 → プライバシーとセキュリティ で、「アクセシビリティ」と「オートメーション」の両方で Layout PinSpot をオンにしてください（オートメーションでは、「System Events」を許可します）。初回起動の案内画面から、それぞれの設定画面を開けます。

許可の一覧に Layout PinSpot が見つかりません

設定画面の「+」を押して、Layout PinSpot.app を追加するか、Finder の Layout PinSpot.app を一覧へドラッグしてください。案内画面の「Layout PinSpot.app を Finder で表示」で、場所を開けます。

どのウィンドウが対象ですか？

標準では、今表示しているデスクトップのウィンドウです。メニューの「デスクトップをまたいで適用する」をオンにすると、保存したアプリのウィンドウを、他のデスクトップからも、今のデスクトップに集めて並べます。

外部ディスプレイをつないだら、自動で戻りますか？

メニューの「ディスプレイをつないだ・外したとき、配置を自動で戻す」をオンにすると、つないでいるディスプレイの組み合わせと同じ組み合わせで保存した配置があれば、自動で適用します。組み合わせが違う配置は、使われません。

どんな情報を保存しますか？

保存した配置（名前、アプリ名、ウィンドウのタイトル、位置、大きさ、表示していたディスプレイ）を、お使いの Mac の中だけに置きます。通信はせず、開発者にも送られません。ウィンドウの内容や画面は見ません。くわしくはプライバシーポリシーをご覧ください。

保存した配置を消したい

メニューで、配置の行の「…」→「削除」で、1つずつ消せます。すべて消すには、アプリを削除したうえで、フォルダ「~/Library/Containers/com.pinspot.app」も削除してください（アプリを削除しただけでは、保存データは残ります）。

14 日間のお試しと、Pro について

14 日間は、すべての機能を無料で使えます。その後は、保存と適用ができなくなります（保存した配置は消えません）。Pro（買い切り・サブスクではありません）を購入すると、すぐに元どおり使えます。

Pro を買ったのに、使えません

メニューの「購入を復元」を押してください。購入したときと同じ Apple ID でサインインしている必要があります。返金は Apple が行います（reportaproblem.apple.com）。

対応している環境は？

macOS 13 以降の Mac です。表示言語は、日本語・English・繁體中文・한국어・Deutsch・Français・Español に対応しています。

FAQ

Windows don't move / it says "Permissions required"

Layout PinSpot uses two macOS permissions to read and move the position and size of windows. In System Settings → Privacy & Security, turn Layout PinSpot on under both "Accessibility" and "Automation" (under Automation, allow "System Events"). The introduction window opens each settings pane for you.

Layout PinSpot isn't in the permission list

Click "+" in the settings pane and add Layout PinSpot.app, or drag Layout PinSpot.app from Finder into the list. "Show Layout PinSpot.app in Finder" in the introduction window shows you where it is.

Which windows does it use?

By default, the windows of the desktop you are currently viewing. If you turn on "Apply across desktops" in the menu, applying also gathers the saved apps' windows from your other desktops onto the current one.

Does it restore automatically when I connect a display?

Turn on "Auto-restore the layout when a display is plugged in or unplugged" in the menu. Layout PinSpot then applies the layout you saved for exactly the set of displays that is connected. Layouts saved for a different set of displays are not used.

What does Layout PinSpot store?

Your saved layouts (their names, and for each window the app name, window title, position, size and display) — only on your Mac. Layout PinSpot does not use the network and nothing is sent to the developer. It never reads the content of windows or the screen. See the Privacy Policy.

How do I delete a saved layout?

In the menu, open the "…" next to the layout and choose "Delete". To remove everything, delete the app and also the folder "~/Library/Containers/com.pinspot.app" (deleting only the app leaves the saved data behind).

About the 14-day trial and Pro

All features are free for 14 days. After that, saving and applying are locked (your saved layouts are kept). Buying Pro (a one-time purchase, not a subscription) unlocks everything again right away.

I bought Pro but it's still locked

Choose "Restore Purchases" in the menu. You need to be signed in with the same Apple ID. Refunds are handled by Apple (reportaproblem.apple.com).

Which systems are supported?

Macs running macOS 13 or later. The app is available in Japanese, English, Traditional Chinese, Korean, German, French and Spanish.
